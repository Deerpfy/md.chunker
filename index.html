About this tool

About Markdown Chunker

Splits a markdown file into smaller pieces by target size or by heading boundary. All processing happens in your browser. Nothing is uploaded.

Part of AdHub, an open collection of single-file offline tools. Works fully from a local file with no internet connection.

UTF-8 safe byte counting. Code fences kept intact when possible. ZIP packaging via inline STORE-method writer (no compression, valid everywhere).
